# aws-devops-labs

Labs AWS pratiques, réalisés sur un compte personnel, dans le cadre d'un parcours
DevOps / SysOps. Chaque lab est fait en 4 passes : console, AWS CLI, Terraform,
puis panne volontaire et diagnostic.

| Lab | Sujet | Statut |
|---|---|---|
| 01 | Sécurisation du compte et IAM | En cours |
| 02 | VPC from scratch + EC2 | À faire |
| 03 | S3 + rôle IAM pour EC2 | À faire |
| 04 | Terraform + state distant + CI | À faire |
| 05 | Monitoring CloudWatch + SNS | À faire |
| 06 | ALB + Auto Scaling | À faire |
| 07 | Automatisation avec Lambda | À faire |
| 08 | EKS réel | À faire |

## Règles appliquées
- Aucun secret ni state Terraform dans le dépôt
